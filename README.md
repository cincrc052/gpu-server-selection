## 三款显卡一样，$2687 的差价买的是什么

三款里差价最大的两项是内存和网络。$1109.99 那款配 512GB 内存、10G×2 加 40G/100G×2 网口；$3796.99 那款内存翻到 1024GB，网口换成 25G 光口×2；$2920.99 那款内存仍是 512GB，但给了一个 200G 端口，存储也从单块 M.2 变成两块 7.68TB U.2。

对多卡机器来说，内存容量决定你能同时喂多少数据给 8 张卡，网口决定这台机器跟外部存储、其他节点之间的传输速度。如果你的任务是把一批图片丢进去批量出图，或者跑切片后的推理任务，512GB 内存 + 10G 网口通常不是瓶颈，$1109.99 那款就是同一批显卡里最省的选择。反过来，要接共享存储做多机训练、或者单次数据集就上百 GB，$2687 的差价买的是不让你卡在数据供给上。

判断方法很简单：先算你单次任务的数据集大小，如果它连 512GB 内存的零头都用不到，多花的钱换不来速度。

## "$X/月起"是怎么算出来的

黑五页面上最常见的话术是"$X/月起"，这个数字多半是两年付折算出来的月均价，不是你第一个月要付的钱。

拿一份可核对的对照：某美国商家黑五页上，Linux Express 的普通月付优惠价是 $4.19/月，同一款选 24 个月周期，折算下来是 $2.52/月。GPU 那一栏标的 $37/月、$119.50/月，同样是两年付折算后的数字。也就是说，你要享受这个价，得先一次性付清两年。

## 按显存选档位，别按显卡名字选

同一张卡的名字好记，但决定你能跑什么的是显存。下面这些档位对应的用途，都能在产品参数里找到依据：

- **4GB（Quadro P1000 这类）**：远程图形桌面、视频转码、轻量视觉处理。跑 Stable Diffusion 基本不行，SD 1.5 实际要 8GB 才顺手。
- **8GB（RTX 3060 Ti）**：SD 1.5 出图、小模型推理、1080p 剪辑加速。黑五折算价 $119.50/月那一档。
- **16GB（RTX A4000）**：SDXL 出图、7B 模型量化推理、中等强度渲染。折算价 $139.50/月。
- **24GB（RTX 4090）**：单卡能覆盖 7B–13B 量化推理、SDXL/Flux 出图、实时渲染。LightLayer 的整机就是 8 张这个卡。
- **32GB GDDR7**：以 NVIDIA RTX PRO 4500 Blackwell 服务器版为例，32GB GDDR7、800 GB/s 带宽、单精度 51 TFLOPS，官方定位是 AI 开发、小模型推理、边缘 AI、视频分析、虚拟工作站。
- **80GB HBM2e（H100）**：大模型微调与推理的主力档位，折算价 $1169.55/月。
- **96GB GDDR7**：RTX PRO 6000 Blackwell 服务器版，96GB GDDR7、1597 GB/s 带宽、单精度 120 TFLOPS，面向 LLM 微调与推理、生成式图像视频、FP32 高性能计算。

从 16GB 到 80GB，显存差 5 倍，月费差 8 倍多。这不是商家乱定价，是大显存卡本身稀缺，而且 HBM 和 GDDR 是两种东西。选档位时先问自己模型要占多少显存，再往回推价格，比对着显卡型号比价靠谱。

## 常见问题

**黑五价续费也是这个价吗？**
LightLayer 双十一那四款明确写了续费同价。GPU 整机三款的页面没有写续费政策，下单前问清楚，别默认沿用活动价。

**一定要签长约才能拿到低价吗？**
双十一条款写明季付、半年付、年付都能同享活动价，并可叠加额外折扣，短周期也能用。GPU 页面没有标周期折扣，看到的价格就是当期价。

**4GB 的卡能跑 AI 绘图吗？**
不能。4GB 那档是远程桌面、转码、轻量图形处理用的，SD 1.5 起步要 8GB，SDXL 建议 16GB 起。

**8 卡整机我一个人用得上吗？**
多数情况用不上。单卡 24GB 已经能覆盖出图、13B 量化推理、视频剪辑加速。8 卡是给能切成 8 份并行跑的批量任务准备的，用不上就是白付钱。

**搜"黑五"为什么看到的是双十一活动？**
时间上两个档期挨着，商家常把双十一和黑五合并成一个促销季，但具体到 LightLayer，目前公开的只有双十一这批限量机型，黑五的 GPU 专场还没出现在页面上。
